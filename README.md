# DSA in C++

A collection of Data Structures and Algorithms problems solved using **C++**. This repository is focused on building strong problem-solving skills, understanding core DSA concepts, and preparing for coding interviews and competitive programming.

Topics include arrays, strings, linked lists, stacks, queues, trees, graphs, recursion, dynamic programming, sorting, searching, greedy algorithms, and more.

Each solution aims to be clear, efficient, and easy to understand, with a focus on **time and space complexity**.

**Language:** C++
**Focus:** DSA • Problem Solving • Competitive Programming • Interview Preparation
